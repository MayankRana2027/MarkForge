# ✨ MarkForge — Live Markdown Editor

MarkForge is a **modern, browser-based Markdown editor** with real-time HTML preview, built using **HTML, CSS, and JavaScript**.

It provides a smooth writing experience with instant rendering, formatting tools, and export functionality — all in a clean UI.

---

## 🚀 Features

- ⚡ **Real-time Preview** — See HTML output instantly as you type
- 📝 **Rich Toolbar** — Quick formatting (Headings, Bold, Lists, Code, etc.)
- 📊 **Live Stats** — Word count, character count, line count, cursor position
- 📤 **Export HTML** — Download your Markdown as a standalone HTML file
- 📋 **Copy HTML** — Copy rendered HTML directly to clipboard
- 🧹 **Clear Editor** — Reset content instantly
- 📏 **Resizable Panels** — Adjust editor and preview layout
- 🎨 **Beautiful UI** — Clean dark editor + styled preview output

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3 (Custom UI + Fonts)**
- **JavaScript (Vanilla JS)**
- **Marked.js** (for Markdown parsing)

## ▶️ How to Run


2. Open the project folder

3. Run the app:
   - Simply open `index.html` in your browser

## ✍️ How to Use

- Write Markdown in the **left panel**
- View live HTML output in the **right panel**
- Use the toolbar for quick formatting
- Export your work using the **Export button**
